# 💧 Charity Water Game

An interactive browser game that raises awareness about clean water access worldwide.

## About

Help provide clean water to communities in need by catching falling water drops! This fun and educational game teaches players about the importance of clean water while challenging them to collect as many drops as possible.

## How to Play

1. **Open the game**: Simply open `index.html` in your web browser
2. **Click "Start Game"** to begin
3. **Move your bucket** (🪣) using your mouse or finger (on mobile)
4. **Catch water drops** (💧) to score points - each drop is worth 10 points
5. **Avoid pollution** (💀) - catching these will cost you a life!
6. **Race against time** - You have 30 seconds to collect as many drops as possible
7. **See your impact** - At the end, see how many liters of clean water you've helped provide!

## Game Features

- ⏱️ **30-second challenge** - Fast-paced action
- ❤️ **3 lives system** - Be careful to avoid pollution
- 📊 **Score tracking** - Every 10 points = 1 liter of clean water
- 🎮 **Mouse & touch controls** - Play on desktop or mobile
- 🎯 **Impact calculation** - See how many people you've helped
- 🎨 **Beautiful design** - Engaging visuals and smooth animations

## Installation

No installation required! Just:

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start playing!

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no dependencies)

## Educational Impact

This game raises awareness about:
- The global clean water crisis
